# EEEVis

**Interactive Electrical & Electronic Engineering Visualizer**

EEEVis is a small collection of interactive visualizers and virtual lab tools for selected EEE courses.

### Courses

- **Power Electronics**
- **Semiconductor Physics & Devices**
- **Microprocessor & Interfacing**
- **Digital Signal Processing**

The main `index.html` serves as a hub for accessing the individual visualizers hosted through GitHub Pages.

Built as an ongoing collection of interactive EEE course projects.

[Open EEEVis](https://mahmudul28.github.io/EEEVis/)
